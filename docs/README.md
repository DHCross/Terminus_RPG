# Terminus RPG Documentation

This directory contains all documentation for the Terminus RPG project.

## Structure

### `/game-design` 
Core game system design, lore, and world-building documentation.
- **TerminusRPG.md** - Main game system rules and mechanics
- **Terminus RPG 5.9.26.md** - Specific version documentation
- **gazetteer.md** - World locations and geography
- **setting_foundation.md** - Core setting and world fundamentals
- **terminus_campaign_setting.md** - Campaign and adventure setting details
- **terminus_rpg_free_alpha_v0_1.md** - Alpha version specification
- **Mental_and_Monster_Design.md** - Character and creature design guide

### `/development`
Development progress and implementation notes for the Terminus system.
- **phase-1-complete.md** - Phase 1 completion summary
- **phase-2-complete.md** - Phase 2 completion summary
- **phase-3-complete.md** - Phase 3 completion summary
- **rebuild-phases.md** - Development rebuild phases
- **sherlog-onboarding.md** - Sherlog system onboarding guide
- **version-aware-rag-memory-enhancements.md** - RAG memory system notes

### `/system`
General system information and administrative documentation.
- **personalhistory.md** - Project history and background

## Contributing

When adding documentation:
1. Place game design docs in `/game-design`
2. Place development progress notes in `/development`
3. Place administrative/system docs in `/system`
4. Update this README if you create new categories
